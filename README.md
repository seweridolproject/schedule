(Telegram-бот)

Бот показывает расписание, замены и время пар по выбранной группе. Данные берутся с сайта mstimetables.ru, бот сам их разбирает (парсинг HTML) и кэширует на 5 минут.

## Технологии
Python 3.10+, aiogram 3, aiohttp, BeautifulSoup4, SQLite

## Команды
| /start | Выбор группы |
| /schedule | Расписание на сегодня |
| /tomorrow | Расписание на завтра |
| /week | Расписание на неделю |
| /replacements | Замены и переносы на неделе |
| /bells | Время пар |

## Структура проекта
- `bot.py` - обработчики команд и запуск
- `timetable.py` - загрузка и разбор страницы расписания, форматирование
- `db.py` - SQLite: группы (название + ссылка) и пользователи
- `bot.db` - файл базы (создаётся автоматически)
